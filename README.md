# Bearing Atlas — демоверсия

Статический прототип каталога для проверки на Vercel.

## Что работает

- Поиск по обозначению и фильтрация по d, D, B.
- Карточка выбранной позиции.
- Избранное с хранением в текущем браузере.
- Копирование текста заявки (в защищённом HTTPS-контексте).
- Макет тарифов FREE/PRO: расшифровка полностью заблокирована в FREE.
- Адаптивная вёрстка.

## Ограничения

- Всего шесть **демонстрационных** типоразмеров. Это НЕ проверенная база для технических решений.
- Не реализованы регистрация, серверная база, действующие заявки, подтверждённые аналоги, PRO-подписка и оплата.
- Никаких реальных обращений к серверу или сбора персональных данных нет.
- Домен bearingatlas.ru не подключён.

## Локальный запуск

Откройте `index.html` в браузере или выполните `python3 -m http.server 8000` в папке проекта и откройте http://localhost:8000.

## Публикация на Vercel

1. Создайте GitHub-репозиторий и загрузите **файлы из этой папки в корень репозитория**.
2. В Vercel выберите Add New → Project → Import Git Repository.
3. Для проекта выберите Framework Preset: **Other**. Build Command оставьте пустой, Output Directory: `.` (корневая папка).
4. Нажмите Deploy. После завершения Vercel покажет временный адрес вида `имя-проекта.vercel.app`.
5. Проверьте поиск `6205`, размеры `d=25`, карточку, избранное, мобильный экран и окно PRO.
6. К REG.RU и DNS переходите **после** проверки и отдельного решения о подключении домена.

Для реального продукта потребуется полноценный backend, валидированные технические данные, аутентификация и коммерческие условия.
